# 设计规范

Nagi 使用中性背景、金色强调和胶囊控件。内容卡片不使用阴影，模糊仅用于导航和浮动控件。
本文是通用视觉规范；页面行为见 [页面说明](screens.md)，检查方法见 [界面验收](review.md)。
实现位于 `NagiTheme.kt` 和共享 Compose 组件中。

## 色彩

主要设计变量如下，其他状态色见 `NagiTheme.kt`。页面复用语义化设计变量，不自行复制色值。

| 设计变量 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| GroupedCanvas | `#F6F7F9` | `#0D0E11` | 页面背景 |
| CardSurface | `#FFFFFF` | `#18191D` | 内容卡片 |
| CardBorder | `#E8EAED` | `#26282E` | 边框、分隔线 |
| InsetContainer | `#F0F2F5` | `#22242A` | 输入框、内嵌区域 |
| TextPrimary | `#111827` | `#F3F4F6` | 标题、正文 |
| TextSecondary | `#4B5563` | `#9CA3AF` | 作者、时间等辅助文字 |
| TextMuted | `#9CA3AF` | `#6B7280` | 弱化状态；不用于需要正常文字对比度的信息 |
| GoldAccent | `#B58838` | `#D6BA8B` | 强调图标 |
| GoldText | `#8C651E` | `#E5C494` | 金色文字 |
| GoldContainer | `#FBF5EB` | `#2D251A` | 选中、高信号标签背景 |
| GoldSolidFill | `#B8863B` | `#D6BA8B` | 实心主按钮 |
| GoldSolidText | `#18120A` | `#18120A` | 实心主按钮文字 |
| Destructive | `#DC2626` | `#F87171` | 删除、明确拒绝等警示 |

金色用于选中态、精选、楼主、合集、当前项和回复数 ≥100 的热帖。
普通分类前缀与 0–99 回复数使用中性色；排序按钮是控件，不使用内容标签的金色背景。
通知红点表示未读提醒，不表示破坏性操作。

普通文字需达到 4.5:1 对比度，大字及适用的非文本图形需达到 3:1。
`TextMuted` 在白底上的对比度约为 2.54:1，不能因其设计变量名称就认为适合辅助正文。
半透明表面的对比度应以合成后的背景检查，不作全主题合规声明。

## 排版

使用系统无衬线字体；中文默认字距为 0，计数、时间和楼层使用 `tnum` 等宽数字。

| 样式 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 品牌标题 | 28 / 34sp | 半粗 |
| 顶栏标题 | 16 / 22sp | 半粗 |
| 章节标题 | 18 / 24sp | 半粗 |
| 分区标题 | 13 / 18sp | 中等，字距 0.2sp |
| 主题标题 | 15.5 / 22sp | 中等 |
| 界面正文 | 15 / 22sp | 常规 |
| 帖子正文 | 16 / 26sp | 常规，可由阅读偏好调整 |
| 标签 | 11 / 14sp | 半粗 |
| 回复数 | 11.5 / 15sp | 半粗 |

正文链接使用 GoldText 与下划线，保留原生文本链接语义和换行，不只靠颜色区分。
长昵称和元数据允许换行；空间不足时改用上下排列，不靠截断或缩小字体维持双列。
时间按系统时区显示：当天用相对时间，当年其他日期用 `MM-dd HH:mm`，跨年带年份。
无效数值时间显示 `—`，无法解析的文本保留原文。

## 共享组件

- 媒体浏览层使用主题背景与独立安全操作区；图片变换裁剪在内容区域内，不覆盖操作控件。
- 卡片：零阴影、1dp 边框；分组圆角 20dp，主题卡片 16dp。
- 按钮、搜索条和分段控件：胶囊或圆形；每个独立操作热区至少 48×48dp。
  圆形导航按钮默认视觉直径 42dp；分段标签等宽，大字号时可换行增高。
- 开关：平面白色滑块；浅色开启轨道 `#C09D73`、关闭 `#E5E7EB`，深色分别为
  `#D6BA8B`、`#2A2C33`。暴露开关角色及开关状态。
- 用户文字标记：中性胶囊，复用标签字号，水平 8dp、垂直 2.5dp 内边距；与同列作者信息居中对齐。
  不染金色以免混同楼主身份；文字自然换行，不挤占昵称或元数据。
- 操作图标：1.6dp 单线矢量，圆角端点，不用表情符号代替。
  远程版块图片属于内容标识，保留原色，放入 32dp、10dp 圆角槽；加载或失败时只留背景。
- 磨砂：36dp 有界背景模糊，叠加渐变釉层、颗粒和细描边。语义基色浅色为白色 85%，
  深色为 CardSurface 88%；菜单底色为 96%。这些不是最终合成像素值。
  Android 31 以下、省电、关闭系统动画或禁用模糊时使用静态回退。帖子正文不应用实时模糊。

## 列表与状态

所有分页列表应在接近已加载末尾时异步追加，不以底部上一页、下一页或加载更多按钮作为连续浏览入口。
追加保留内容和位置，同一页的在途请求合并，已加载项不重复追加。
失败后保留内容并提供显式重试，不因滚动反复重试；已知末页停止请求，未知总量不伪装成末页。
用户、账号和标签切换需隔离结果，各标签保留独立内容与位置。这是全局要求，尚未完成逐页验收。
不用本地计数或标记暗示服务端同步；实现机制说明留在文档，不在内容页面常驻展示。

加载、空状态、错误、刷新和追加状态分开处理；刷新保留现有内容。
列表按项目独立虚拟化并使用稳定键。窗口变化时保持列表和正文的独立阅读位置，
固定控件避让系统栏、输入法和列表末项。

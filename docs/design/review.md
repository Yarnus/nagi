# 界面验收

按 [设计规范](README.md) 和 [页面说明](screens.md) 检查受影响页面。
使用脱敏数据，至少覆盖浅色 / 深色、320dp 窄屏、1.5x / 2x 字号和宽屏布局。
以下是验收要求，不是已通过清单。

## 通用检查

- [ ] 长昵称、长标题、空元数据不会截断关键信息、重叠或崩溃。
- [ ] 文字与图标对比度符合用途；半透明控件按实际背景检查。
- [ ] 独立控件热区至少 48dp，无障碍名称、角色、选中及禁用状态正确。
- [ ] 系统栏、输入法和浮动控件不遮挡操作或列表末项；大字号下控件可增高。
- [ ] 磨砂静态回退可用，动画关闭时交互正常；隐藏控件不拦截触控或保留动作语义。
- [ ] 加载、空、错误、刷新、追加状态可区分，刷新和失败保留已读内容。
- [ ] 列表独立虚拟化、键稳定；窗口变化和返回导航保持阅读位置。

## 功能回归

| 范围 | 重点场景 |
| --- | --- |
| 滚动分页 | 所有分页列表，包括用户主题 / 回复；接近末尾追加、同页合并、去重、明确重试、已知末页停止、未知边界如实显示；不依赖底部分页按钮 |
| 账号隔离 | 登录、退出、切换时不显示旧计数 / 内容，迟到结果不能恢复旧账号状态 |
| 导航 | 同组版块原地切换；账号页面连续返回不弹空主页，转场期间有效操作不丢失 |
| 子板块设置 | 导航与过滤 ID 分离；错误属性不可写；串行提交、成功后重读第一页、保存与读取失败分开；结果不明跨版块切换仍锁定 |
| 阅读器 | 楼层元数据缺失、客户端回退、跳页 / 跳楼、只看楼主；回复胶囊显隐不跳动，末层可完整滚到控件上方 |
| 图片浏览 | 长图 / 横图适应窗口；双指中心缩放、1–5 倍限制、拖动边界、双击与还原、关闭重开；失败重试；横竖屏与窗口变化、深色 / 大字号、系统栏避让与 TalkBack 操作 |
| 正文链接 | 普通 / 旧式 BBCode 去标签；点击可信主题站内打开并返回原位置；外链和带定位参数链接沿用外部打开；伪装域名、凭据 URL、危险协议不作为站内导航；代码块保持原文 |
| 评分 | 赞踩取消与互切；无回执不猜分；进度不改变楼层高度；失败保留状态，未知结果仅由对应楼层重读解锁；并发刷新不重复累计 |
| 编辑 | 原始 BBCode、所有权、准备失败、草稿隔离；接受后只刷新当前页一次，拒绝保留输入，未知结果关闭重开仍不重发 |
| 私信 | 预填未修改直接退出；有改动才确认；资料来源编辑器不请求收件箱，退出回原标签与位置 |
| 图片上传 | 系统选择 / 取消、支持格式与 10MB 限制、选区插入、多图及删除标签、上传中不可提交 / 关闭、明确拒绝可重试、结果不明不重放；账号切换丢弃迟到结果、发帖草稿恢复附件校验 |
| 表情 | 行内换行、原色与深色底衬、稳定占位、复制原始代码；正反选区、输入法组合文本、连续插入、引用前缀及只读状态 |
| 通知 | 0 / 1 / 99 / 100+ / 未知计数；本机计数与已读状态一致，不常驻展示实现机制说明；刷新及空响应不丢历史、重复不重置已读、打开单条 / 全部已读、重启留存；无效目标不可导航 |
| 资料 | 匿名 / 缺失字段、签名展开、独立标签缓存、重建从第一页读取、自身 / 游客私信入口 |
| 用户标记 | 资料页新增 / 修改 / 删除、24 字符及控制字符校验、匿名无入口；UID 关联、账号 / 游客隔离、Room 4→5 保留原数据、重启留存；中英文标记与昵称 / 楼主标签居中对齐，窄屏大字号不重叠，帖子及两种评论视图同步更新 |
| 开源许可 | 无网络时可读取项目及第三方许可；长文本可滚动，关闭后返回关于页 |
| 本地收藏 | 版块 / 合集区分、目录和抽屉状态一致、账号隔离、Room 2→3 迁移保留数据 |
